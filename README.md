# SkillForge Frontend

Production-oriented React/Vite frontend for the SkillForge freelance marketplace.

## Run
1. Copy `.env.example` to `.env`.
2. Set `VITE_API_URL` to the running backend API.
3. Install dependencies with `npm install`.
4. Start with `npm run dev`.

The UI uses authenticated API requests for marketplace, user, admin and analytics data. No seed/demo project records are bundled in the frontend.
